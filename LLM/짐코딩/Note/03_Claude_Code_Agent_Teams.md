1. Subgagent란

- 메인과 분리된 별도 컨텍스트에서 작업하고, 결과 요약만 리턴

- 파일 100개를 뒤져도 메인 컨텍스트는 깨끗하게 유지

- 메인 컨텍스트를 아끼면서 더 길고 복잡한 작업을 이어갈 수 있음

2. 서브에이전트의 한계

- 직접 대화 불가

- 요약만 리턴

    - 중간에 발견한 미묘한 단서들은 사라지고 요약 몇 줄 만 들어옴
    
- 메인 병목

    - 메인이 혼자서 모든 서브에이전트 관리 컨텍스트가 빠르게 차버림
