1. 팀원 = 새 Claude Code 세션 vs 서브에이전트 = 격리된 환경

    - 핵심 차이 = 스킬 상속 방식

    - 팀원은 프로젝트의 모든 스킬을 전부 자동으로 가져가고 서브에이전트는 골라서 넣어줘야 함 

2. 계획 먼저, 코딩 나중 

    - 프롬프트에 한 줄 추가 : 각 팀원이 변경하기 전에 plan approval을 받도록 해줘 

    - 이렇게 하면 

        - a. 팀 생성 (plan approval)

        - b. 계획 분석 (plan mode)

        - c. 계획 제출 (리드에게 보고)

        - d. 승인/거절 (리드가 판단)

        - e. 구현 시작 (승인 후 실행)

3. 모델 믹싱 = 핵심 전략

- 리드 : Opus (조율, 추론, 계획 검토, 작업 분해, 품질 판단)

- 팀원 : Sonnet (코드 생성, 파일 편집, 실행, 구현 작업)

- 프롬프트에 팀원은 모두 Sonnet을 사용해 추가 

4. 4가지 비용 절감 전략

- 팀이 진짜 필요한지 판단

    - 소통 불필요한 작업은 서브에이전트 사용. 조율 오버헤드 제거 

- 최소 인원으로 시작

    - 3~5명이면 충분. 10명은 수확 체감이 심함 

- 끝난 팀원은 즉시 종료

    - 세션이 살아있으면 계속 토큰 소모. 바로 종료 요청

- CLAUDE.md에 비용 지침

    - broadcast 금지. 완료 후 즉시 종료. 반복 3회 제한 

5. 훅 비교 

- TeammateIdle : 팀원이 할 일을 끝내고 쉬고 있을 때 발동 

- TaskCompleted : 팀원이 태스크를 "완료"처리할 때 발동  (팀장이 결과물 검토 후 돌려보내는 것)
