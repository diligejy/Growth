## 기술 준비

### 데이터 모델링
- [ ] Star Schema 설명 가능 (Fact + Dimension 테이블)
- [ ] 파티셔닝/클러스터링 설명 가능
- [ ] SCD (Slowly Changing Dimension) Type 2 개념 확인

### SQL
- [ ] 윈도우 함수 설명 가능 (ROW_NUMBER, LAG, LEAD)
- [ ] 재방문율/코호트 분석 쿼리 작성 가능
- [ ] JOIN 최적화 원칙 설명 가능

### 데이터 품질
- [ ] dbt tests (not_null, unique, accepted_values) 설명 가능
- [ ] 데이터 품질 모니터링 방안 설명 가능
- [ ] 백필(backfill) 프로세스 설명 가능

### 최적화
- [ ] BigQuery 비용 최적화 방안 3가지 이상 설명 가능
- [ ] Materialized View 사용 사례 설명 가능
- [ ] dbt incremental model 개념 확인

### 파이프라인
- [ ] Airflow Idempotency 개념 설명 가능
- [ ] INSERT OVERWRITE vs MERGE 차이 설명 가능
- [ ] DAG 실패/재시도 처리 방안 설명 가능

## 비즈니스 준비

### 당근 현황
- [ ] 2025년 핵심 지표 암기 (MAU 2,000만, 광고 매출 99.7%)
- [ ] MAU 정체 vs DAU/사용시간 성장 의미 설명 가능
- [ ] 연결/별도 기준 영업이익 차이 설명 가능

### 비즈니스 모델
- [ ] 하이퍼로컬 광고 개념 설명 가능
- [ ] 비즈프로필 데이터 흐름 설명 가능
- [ ] 당근알바/부동산/중고차 데이터 설계 가능

### 경쟁사 비교
- [ ] 번개장터/중고나라와의 차이점 설명 가능
- [ ] 광고 중심 vs 수수료 중심 모델 비교 가능

### 지표 설계
- [ ] "동네 연결" 측정 지표 3가지 이상 제시 가능
- [ ] 매너온도 개선 방안 3가지 이상 제시 가능
