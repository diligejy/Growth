# 당근마켓 비즈니스 모델 분석

> DAE 관점에서 본 수익원, 데이터 흐름, 성장 전략

---

## 핵심 인사이트 (3줄 요약)

1. **하이퍼로컬 광고**가 매출의 90%+ = 지역 기반 타겟팅 데이터가 핵심 자산
2. **비즈프로필/버티컬 서비스**로 생태계 확장 = 새로운 데이터 영역
3. **당근페이**로 Lock-in 강화 + 결제 데이터 확보

## 2. 핵심 사업별 데이터 흐름

### 2.1 하이퍼로컬 광고

**비즈니스 로직**:
- 동네 소상공인이 특정 반경 + 관심사로 타겟팅
- 광고 효과 = 노출 → 클릭 → 채팅/문의 → 전환

**DAE가 설계할 데이터**:
```
사용자 데이터:
├── 위치 데이터 (GPS, 등록 지역)
├── 관심 카테고리 (검색 패턴, 조회 이력)
└── 행동 패턴 (클릭, 채팅, 거래 완료)

광고주 데이터:
├── 업종, 위치, 예산
├── 타겟 설정 (반경, 연령, 관심사)
└── 광고 효과 (ROAS, 전환율)
```

### 2.2 비즈프로필

**비즈니스 로직**:
- 동네 가게의 홍보 채널
- 예약, 결제, 단골 관리 기능 제공

**DAE가 설계할 데이터**:
```
가게 정보:
├── 카테고리, 위치, 영업시간
└── 메뉴/상품 정보

고객 행동:
├── 방문, 예약, 결제
├── 리뷰, 별점
└── 단골 등록/재방문 주기

커머스 데이터:
├── 예약 전환율
├── 결제 성공률
└── 단골 재구매율
```

### 2.3 버티컬 서비스 (알바/부동산/중고차)

**당근알바 데이터**:
```
구인 측:
├── 공고 정보 (업종, 시급, 위치, 시간)
├── 지원자 프로필 매칭 점수
└── 채용 전환율 (지원 → 면접 → 채용)

구직 측:
├── 이력서 정보 (경력, 선호 지역/업종)
├── 지원 이력
└── 채용 성공률
```

**부동산/중고차**:
```
신뢰 데이터:
├── 매물/차량 정보 정확도
├── 중개사/판매자 매너온도
├── 거래 완료율
└── 분쟁 발생률
```

### 2.4 당근페이

**비즈니스 로직**:
- 결제 편의성으로 생태계 Lock-in
- 구매력 데이터 확보

**DAE가 설계할 데이터**:
```
결제 데이터:
├── 거래 금액, 수단, 시간
├── 사용자 구매력 세그먼트
└── 충전/환불 패턴
```

## 3. 데이터-비즈니스 연결망

```
┌─────────────────────────────────────────────────────────────┐
│                   데이터 → 비즈니스 가치                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  사용자 행동 데이터                                         │
│       │                                                     │
│       ├──→ 광고 타겟팅 정교화 ──→ 광고 ROAS 상승            │
│       │                        ──→ 광고주 유치              │
│       │                                                     │
│       ├──→ 추천 알고리즘 개선 ──→ 거래 성사율 상승        │
│       │                        ──→ 사용시간 증가            │
│       │                                                     │
│       └──→ 매너온도/신뢰도 모델 ──→ 플랫폼 신뢰성 강화      │
│                                  ──→ 안전한 거래 환경       │
│                                                             │
│  로컬 데이터 (위치 + 상권)                                  │
│       │                                                     │
│       ├──→ 하이퍼로컬 광고 정밀 타겟팅                      │
│       └──→ 동네 커뮤니티 활성화                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 4. 경쟁사와의 전략적 차이

| 구분 | 당근마켓 | 번개장터 | 중고나라 |
|------|----------|----------|----------|
| **핵심 차별화** | 동네 기반 신뢰 | 안전결제(에스크로) | 커뮤니티 |
| **수익 모델** | 광고 99.7% | 수수료 50%+ | 수수료 중심 |
| **데이터 강점** | 위치+행동 데이터 | 거래 안전성 데이터 | 커뮤니티 데이터 |
| **성과** | 흑자 | 2024 흑자전환 시도 | 적자 지속 |

### 번개장터 에스크로 전환의 시사점

```
Before: C2C 직거래 중심
After:  에스크로 기반 안전결제 (2024년 8월 도입)
결과:  C2C 거래 +93%, 거래액 +76%

→ 안전성이 중고거래 사용자의 핵심 니즈
→ 당근의 '동네 신뢰' 외에 '안전결제' 옵션도 고려 가능성
```

## 5. 성장 전략과 데이터 요구사항

### 황도연 대표 전략

> "MAU가 정체되어 있지만 앱 사용성이 크게 늘었다"
> "무리하게 새 사용자를 끌어오기보단 '매일 쓰는 앱'을 만드는 데 집중"

### 데이터적 해석

| 전략 | 데이터 요구사항 | DAE 역할 |
|------|----------------|----------|
| 생활밀착형 서비스 확대 | 알바/모임/커뮤니티 데이터 통합 | 통합 데이터 모델 설계 |
| 사용시간 증대 | 세션 깊이 분석, 퍼널 최적화 | 이벤트 추적 인프라 |
| 광고 사업 심화 | 광고 효율성 측정, ROAS 분석 | 광고归因 모델링 |
| 신규 비즈니스 | 수수료 모델 검증 데이터 | 수익성 분석 지표 설계 |

## 면접 답변 가이드

### Q: "당근은 어떻게 돈을 버나요?"

**답변 프레임**:
```
"핵심은 하이퍼로컬 광고입니다. 매출의 99.7%를 차지합니다.

동네 소상공인이 반경 3km 내 '이사' 관심 고객에게 
광고를 노출하는 방식입니다.

DAE로서 저는:
1. 사용자 위치/관심사 데이터를 정제하여 광고 타겟팅 정교화
2. 광고 노출→클릭→전환 퍼널을 측정하여 ROAS 개선
3. 비즈프로필의 커머스 데이터를 활용한 새 광고 포맷 개발

에 기여하고 싶습니다."
```

### Q: "데이터가 비즈니스에 어떻게 기여하나요?"

**답변 프레임**:
```
"3가지 측면에서 기여합니다:

1. 광고 타겟팅: 사용자 행동 데이터로 광고 ROAS 상승
2. 추천 알고리즘: 거래 매칭 품질 개선으로 사용시간 증대  
3. 신뢰 모델: 매너온도 등 신뢰 지표로 안전한 거래 환경 조성

DAE는 이 모든 데이터의 파이프라인과 품질을 책임집니다."
```
