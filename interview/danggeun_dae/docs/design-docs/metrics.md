# 당근마켓 핵심 지표 분석

> 데이터 분석가 관점에서 본 당근 현황 및 인사이트

---

## 핵심 인사이트 (3줄 요약)

1. **MAU 정체 속 DAU/사용시간 성장** = "매일 쓰는 앱" 전략 성공
2. **광고 매출 99.7%** = 검증된 수익 모델, 흑자 구조 확립
3. **자회사 투자로 연결 이익 감소** = 미래 성장을 위한 전략적 투자

---

## 1. 사용자 지표 (2025년 3월 기준)

| 지표 | 수치 | 성장률 | 데이터적 의미 |
|------|------|--------|---------------|
| 누적 가입자 | 4,300만 | - | 국민 1/3 이상 가입, Acquisition 포화 |
| MAU | 2,000만 | 정체 | 성숙기 플랫폼 진입 |
| WAU | 1,400만 | - | 주간 리텐션 70% (충성도 높음) |
| DAU | - | 2023년 +9.7% | Engagement 심화 성공 |
| 앱 사용시간 | - | 2024년 +13.2% | 광고 인벤토리 확대 = 수익 직결 |

### 데이터 해석

```
MAU 정체 + DAU 성장 = 방어적 성장(Defensive Growth)
- 새 사용자 유입 대신 기존 사용자 사용 빈도 증대
- 앱 사용시간 증가가 광고 매출 성장으로 연결
```

## 2. 재무 지표 분석

### 매출 성장률 추이

| 연도 | 매출 | 성장률 | 영업이익 | 비고 |
|------|------|--------|----------|------|
| 2022 | 499억 | +94% | 적자 | - |
| 2023 | 1,278억 | +156% | 흑자전환 | 수익 모델 검증 |
| 2024 | 1,891억 | +48% | 376억 | 흑자 유지 |
| 2025 | 2,707억 | +43% | 146억 (연결) | 자회사 투자 확대 |

### 연결 vs 별도 기준 분석

| 기준 | 매출 | 영업이익 | 영업이익률 | 의미 |
|------|------|----------|-----------|------|
| **연결** | 2,707억 | 146억 | 5.4% | 자회사 손실 반영 |
| **별도** | 2,690억 | 671억 | 24.9% | 본업 수익성 매우 건강 |

**차이 분석**: 525억 차이 = 당근알바, 모임 등 신규 서비스 투자비

### 데이터적 인사이트

```
별도 25% 영업이익률 = 본업(중고거래 플랫폼)은 매우 건강
연결 5.4% = 미래 성장 투자를 위해 의도적 이익 감소
→ 흑자 지속 + 고성장 유지 = 긍정적 시그널
```

## 3. 서비스별 거래 지표

| 서비스 | 지표 | 의미 |
|--------|------|------|
| 중고거래 | 연결 1억 9천만 건 | 핵심 비즈니스 안정적 유지 |
| 당근알바 | 5,000만 회 지원 | 새로운 수익 모델 가능성 |
| 비즈프로필 | 265만 개 (+32%) | 로컬 광고 생태계 확장 |

### 사용자당 거래 분석

```
누적 가입자 4,300만 → 연간 중고거래 1.9억 건
= 가입자당 연간 평균 4.4회 거래
= 활발한 거래 생태계 구축됨

당근알바 5,000만 지원:
- 구인 수요에 대한 공급 충족률 분석 필요
- 채용 전환율 = 핵심 성공 지표
```

## 4. 광고 비즈니스 분석

| 지표 | 성장률 | 의미 |
|------|--------|------|
| 광고주 수 | +37% | 시장 확대 |
| 집행 광고 수 | +52% | 기존 광고주 예산 확대 |
| 광고 매출 | +48% | ROAS 검증 완료 |

### 광고 단가 추정

```
2024년 광고 매출 ≈ 1,891억 × 99.7% ≈ 1,885억
광고 수 +52% vs 광고 매출 +48%
→ 단가는 소폭 하락, 볼륨으로 커버

사용자당 광고 매출(ARPU):
2024년: 1,885억 / 2,000만 = 약 94,250원/년
2025년: 2,707억 × 0.997 / 2,000만 = 약 135,000원/년 (+43%)
```

## 5. 경쟁사 비교 인사이트

| 항목 | 당근마켓 | 번개장터 | 중고나라 |
|------|----------|----------|----------|
| MAU | 2,000만 | 680만 | 비공개 |
| 점유율 | ~80% | ~27% | - |
| 수익 모델 | 광고 99.7% | 수수료(3.5%) | 수수료 중심 |
| 영업이익 | 흑자 | 적자 지속 | 적자 지속 |

### 전략적 차이 분석

**당근: 광고 중심 모델**
- 장점: 거래 수수료 없음 → 사용자 유입 장벽 낮음 → 거래 활성화
- 장점: 사용자 증가 → 광고 가치 상승 → 흑자 구조
- 단점: 광고 피로도 관리 필요

**번개장터: 에스크로 전환 성공**
- C2C 거래 +93%, 거래액 +76% = 안전결제가 거래 활성화 핵심
- 수수료가 매출 50%+ = 모델 전환 성공

## 6. AARRR 프레임워크 분석

| 단계 | 지표 | 상태 | 데이터적 의미 |
|------|------|------|---------------|
| Acquisition | 누적 4,300만 | 포화 | 신규 유입 채널 포화 |
| Activation | WAU/MAU 70% | 양호 | 가입자 대부분 주간 활성 |
| Retention | DAU 성장 +9.7% | 성장 | 고착도 상승 중 |
| Revenue | 광고 +48% | 성장 | 사용시간 증가가 수익으로 연결 |
| Referral | 입소문 | 포화 | 4,300만 가입자로 효과 포화 |

### 결론
> 당근은 **Retention/Revenue 단계에 집중한 성숙기 비즈니스**

**답변 프레임**:
```
"表層적으로는 정체지만, 실제로는 의도적인 '방어적 성장' 전략의 결과입니다.

MAU 대신 DAU와 앱 사용시간을 증대시켜:
1. 사용자당 광고 매출(ARPU) 43% 성장
2. '매일 쓰는 앱'으로 브랜딩 강화
3. 광고주 ROAS 상승으로 광고 단가 상승 여력 확보

```
