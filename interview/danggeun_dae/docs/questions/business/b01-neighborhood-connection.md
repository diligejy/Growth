# B1. 동네 연결 측정 지표

> 비즈니스/지표 질문

---

## 질문

"당근의 핵심 가치인 '동네 연결'이 잘 되고 있는지 측정할 수 있는 데이터 지표는 무엇이라고 생각하나?"

---

## 핵심 답변 포인트 (30초 요약)

```
KPI Tree:
├── 지역 기반 거래/활동 활성도
├── 동네별 거래 밀도 (거래 건수/사용자 수)
├── 동네별 응답률 (채팅 응답률, 댓글 반응률)
├── 동네 커뮤니티 참여도
└── 재거래율 (같은 지역 내 반복 거래)
```

---

## 상세 답변

### 동네 연결 KPI Tree

```
[L1: 핵심 목표]
└── 지역 기반 거래/활동 활성도

[L2: 측정 지표]
├── 거래 활성도
│   ├── 동네별 거래 밀도 (거래 건수 / 사용자 수)
│   ├── 평균 거래 완료 시간
│   └── 재거래율 (같은 지역 내 반복 거래 비율)
│
├── 커뮤니케이션 활성도
│   ├── 동네별 응답률 (채팅 응답률, 댓글 반응률)
│   ├── 평균 응답 시간
│   └── 매너온도 분포
│
└── 커뮤니티 활성도
    ├── 동네생활 게시글/댓글 수
    ├── 동네 모임 참여율
    └── 이웃 친구 수 (네트워크 효과)

[L3: 세부 지표]
├── 거래 성공률 (노출 -> 채팅 -> 거래 완료)
├── 분쟁 발생률 및 해결 방식
└── 오프라인 만족도 (리뷰, 매너온도)
```

### 핵심 지표 설명

| 지표 | 계산식 | 목표 |
|------|--------|------|
| **거래 밀도** | 월간 거래 건수 / MAU | 높을수록 활발한 생태계 |
| **응답률** | 채팅 응답 수 / 채팅 수신 수 | 80%+ 유지 |
| **재거래율** | 2회 이상 거래 사용자 / 총 거래 사용자 | 30%+ 달성 |
| **커뮤니티 참여율** | 동네생활 게시글 작성자 / MAU | 10%+ 목표 |

## 꼬리 질문 및 답변

### Q: 동네별로 차이가 클 텐데 어떻게 비교하나요?

**답변**:
```
"정규화(Normalization)가 필요합니다:

1. 인구 밀도 기준
   - 거래 밀도 / 동네 인구
   - 예: 강남(인구 많음) vs 은평(인구 적음) 비교 시

2. 상권 활성도 기준
   - 거래 건수 / 상점 수
   - 상권이 활발한 지역의 자연적 우위 제거

3. 시간 가중치
   - 동네 가입자 증가 추이 고려
   - 신규 동네 vs 성숙 동네 구분 분석

예시: 
- 강남: 거래 1000건 / 인구 10000 = 0.1
- 은평: 거래 300건 / 인구 3000 = 0.1
→ 동일한 '연결도'로 평가"
```

### Q: 어떤 동네가 '건강하지 않다'고 판단하나요?

**답변**:
```
"3가지 신호:

1. 낮은 응답률 (<50%)
   - 채팅 수신에도 응답하지 않는 사용자 증가
   → 관심 저하 또는 좀비 계정

2. 높은 분쟁률 (>5%)
   - 거래 후 불만/신고 증가
   → 신뢰 생태계 붕괴 신호

3. 낮은 재거래율 (<10%)
   - 일회성 거래만 발생
   → 커뮤니티 형성 실패

이 경우:
- 지역별 맞춤 커뮤니티 이벤트
- 동네 리더(오픈톡방 리더) 육성
- 신규 사용자 온보딩 강화"
```

### Q: 동네 연결 vs 매출은 어떤 관계인가요?

**답변**:
```
"강한 상관관계가 있습니다:

동네 연결 ↑
  → 앱 사용시간 ↑ (커뮤니티 활동)
  → 광고 노출/클릭 ↑
  → 광고 매출 ↑

또는:

동네 연결 ↑
  → 거래 성공률 ↑
  → 중고거래 생태계 활성화
  → 당근페이 사용 ↑

데이터로 검증:
- 거래 밀도 높은 지역의 광고 CTR 비교
- 커뮤니티 참여자의 LTV(Lifetime Value) 분석
"
```

## 실전 팁

### 대시보드 설계

```
[동네 연결 대시보드]
├── 전국 지도 (Heatmap)
│   └── 동네별 거래 밀도 색상 표시
├── 트렌드 라인
│   └── 월별 응답률, 재거래율 추이
└── 알림
    └── 이상 지역 (응답률 급감 등) 자동 감지
```

### 면접에서 강조할 점

- **정규화의 중요성**: 단순 거래 건수가 아닌 상대적 지표
- **액션 연결**: 지표가 저하되면 어떤 조치를 취할 것인지
- **비즈니스 연결**: 동네 연결 지표가 매출로 어떻게 연결되는지
