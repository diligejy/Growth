# B2. 매너온도 개선 데이터

> 비즈니스/지표 질문

---

## 질문

"유저의 '매너온도'를 더 신뢰할 수 있게 만들기 위해 추가로 수집하거나 가공해야 할 데이터는?"

---

## 핵심 답변 포인트 (30초 요약)

```
매너온도 개선을 위한 4가지 데이터:
1. 거래 완료 데이터 (무산 vs 실제 거래)
2. 양방향 평가 + 평가자 신뢰도 가중치
3. 행동 패턴 데이터 (노쇼, 분쟁)
4. 시간 가중치 (최근 평가에 높은 가중치)
```

---

## 상세 답변

### 현재 매너온도의 한계

```
현재 (가정):
├── 거래 후 상대방 평가만 반영
├── 일방향 평가 (거래 상대만)
└── 시간 가중치 없음 (과거=최근)

문제:
- 가짜 거래/리뷰 조작 가능
- 실제 거래 없이 평가만 쌓는 경우
- 과거 나쁜 행동이 영원히 따라다님
```

### 개선을 위한 4가지 데이터

**1. 거래 완료 데이터**

| 데이터 | 활용 | 효과 |
|--------|------|------|
| 채팅 -> 거래 완료 전환율 | 실제 거래 의향 측정 | 가짜 거래 필터링 |
| 거래 소요 시간 | 빠른 응답 = 높은 매너 | 효율성 지표 |
| 거래 취소/무산 이유 | 패턴 분석 | 신뢰도 조정 |

```
개선 공식:
매너온도 = f(평가 점수, 거래 완료율, 응답 속도)

- 채팅만 하고 거래 안 한 경우: 평가 무효화 또는 가중치 감소
- 빠른 거래 완료: 보너스 점수
```

**2. 양방향 평가 + 평가자 신뢰도**

```
양방향 평가:
├── 구매자 -> 판매자 평가
└── 판매자 -> 구매자 평가

평가자 신뢰도 가중치:
├── 평가자의 매너온도 (높을수록 가중치 ↑)
├── 평가 패턴 (악의적 평가 여부)
└── 평가 일관성 (같은 사람에게 다른 평가?)

악의적 평가 탐지:
- 항상 극단적 평가만 하는 사용자
- 특정 사용자에게 반복 평가
- 거래 없이 평가만 남기는 경우
```

**3. 행동 패턴 데이터**

| 행동 | 신호 | 처리 |
|------|------|------|
| 노쇼(no-show) | 신뢰 하락 | 매너온도 감점 |
| 가격 흥정 패턴 | 정당 vs 무리 | 과도한 요구 감점 |
| 분쟁 발생 및 해결 | 문제 해결 능력 | 해결 완료 시 복구 |
| 신고 이력 | 반복적 문제 | 가중치 하락 |

**4. 시간 가중치**

```
과거 데이터 감쇠:
- 0-6개월: 100% 가중치
- 6-12개월: 70% 가중치
- 12-24개월: 40% 가중치
- 24개월+: 20% 가중치

최근 개선 보상:
- 최근 3개월 긍정 평가 집중 시 보너스
- 지속적인 좋은 행동 패턴 시 보너스
```

## 꼬리 질문 및 답변

### Q: 가짜 거래/리뷰를 어떻게 탐지하나요?

**답변**:
```
"이상 탐지(Anomaly Detection) 모델 활용:

1. 기술적 신호
   - 동일 IP/디바이스에서 반복 평가
   - 평가 패턴의 시간적 집중도 (1시간 내 10개 평가)
   - 평가 내용 텍스트 유사도 (복사-붙여넣기)

2. 행동적 신호
   - 거래 없이 평가만 있는 경우
   - 거래-평가 시간 간격 비정상 (즉시 평가)
   - A<->B 반복 거래/평가 (자충수)

3. 네트워크 분석
   - 평가 네트워크 그래프 분석
   - 밀집된 평가 클러스터 탐지

조치:
- 의심 케이스: 일시적으로 평가 숨김
- 확정 케이스: 평가 무효화, 계정 제한"
```

### Q: 매너온도가 낮은 사용자를 어떻게 도우나요?

**답변**:
```
"단순 패널티가 아닌 개선 유도:

1. 교육적 접근
   - '매너 가이드' 제공
   - 좋은 거래 사례 노출

2. 점진적 개선
   - 작은 거래부터 시작 (저가 상품)
   - 긍정적 경험 축적 기회 제공

3. 복구 기회
   - 일정 기간 좋은 행동 시 점수 회복
   - 시간 가중치로 자연 회복 가능

단, 원칙적 문제는 엄격히:
- 사기/범죄 행위: 영구 제한
- 반복적 분쟁: 제재 강화"
```

### Q: 매너온도가 너무 높아서 부담스러운 경우는?

**답변**:
```
"좋은 문제입니다:

완화 방안:
- '매너온도 리셋' 요청 기능 (1회)
- 높은 기대치 관리 (완벽함보다 진정성)
- 매너온도 숨김 옵션 제공

하지만:
- 일반적으로 높은 매너온도는 긍정적 신호
- 문제는 '매너온도가 낮은 것'이 더 큰 진입장벽"
```

## 실전 팁

### 매너온도 개선 로드맵

```
Phase 1: 데이터 수집 (1-2개월)
├── 거래 완료 데이터 로깅 강화
├── 행동 패턴 데이터 수집
└── 양방향 평가 시스템 구축

Phase 2: 알고리즘 개선 (2-3개월)
├── 신뢰도 가중치 모델 개발
├── 가짜 리뷰 탐지 모델 배포
└── 시간 가중치 적용

Phase 3: 검증 (1개월)
├── A/B 테스트로 개선 효과 측정
├── 거래 성공률 변화 모니터링
└── 사용자 만족도 조사
```

### 면접에서 강조할 점

- **multi-dimensional**: 단일 지표가 아닌 다차원 평가
- **fairness**: 가짜 평가 필터링으로 공정성 확보
- **improvement opportunity**: 낮은 점수자의 개선 기회 제공
