# C3. 왜 당근인가?

> 컬처핏 질문 (가장 중요)

---

## 질문

"많은 IT 기업 중 왜 하필 '당근'의 DAE여야 하는가?"

---

## 핵심 답변 포인트 (30초 요약)

```
3가지 기둥:
1. 동네 생활 플랫폼에 대한 애정 (구체적 경험)
2. DAE로 기여하고 싶은 부분 (알바 매칭, 광고 최적화)
3. 기술적 강점 (dbt, BigQuery 경험)
```

---

## 상세 답변

### 완성된 답변 예시

```
"3가지 이유에서 당근 DAE에 지원했습니다.

첫째, 동네 생활 플랫폼에 대한 애정입니다.
저는 [본인 동네, 예: 분당]에서 당근으로 
중고 책상을 팔았는데, 10분 만에 동네 주민과 거래가 완료됐습니다.
이 경험을 하며 '이 기능 뒤에는 어떤 데이터가 있을까?' 궁금했습니다.

둘째, 기여하고 싶은 부분이 명확합니다.
당근알바의 5,000만 지원 데이터를 분석해
'어떤 공고가 채용까지 연결되는지' 예측 모델을 만들고 싶습니다.
구직자와 구인자 모두의 경험을 개선할 수 있을 것 같습니다.

셋째, 기술적으로 기여할 수 있습니다.
dbt를 활용한 데이터 모델링과 BigQuery 최적화 경험이 있어
당근의 데이터 환경 개선에 바로 기여할 수 있을 것이라 확신합니다.
"
```

### 구성 요소별 상세

**1. 애정 (Emotional Connection)**

| 요소 | 예시 |
|------|------|
| 구체적 경험 | "최근에 당근으로 [물건]을 [판매/구매]" |
| 감정적 반응 | "신뢰가 느껴졌습니다" |
| 궁금증 | "이 뒤에는 어떤 데이터가 있을까?" |

⚠️ 피할 것:
- "동네 생활이 중요하다고 생각합니다" (너무 추상적)
- "당근이 잘되서" (얕은 이유)
- "연봉이 좋아서" (솔직하지만 부적절)

**2. 기여 (Contribution)**

| 영역 | 기여 방식 |
|------|----------|
| 당근알바 | 구인 성공률 예측, 매칭 알고리즘 개선 |
| 비즈프로필 | 로컬 광고 효과 측정, ROAS 최적화 |
| 중고거래 | 매너온도 개선, 거래 매칭 품질 |
| 데이터 인프라 | dbt 도입, BigQuery 비용 최적화 |

**3. 기술 (Technical Fit)**

| 기술 | 당근에서의 활용 |
|------|----------------|
| dbt | 데이터 모델링, 문서화, 테스트 |
| BigQuery | 파티셔닝/클러스터링 최적화 |
| Airflow | Idempotent 파이프라인 설계 |
| SQL/Python | 복잡한 비즈니스 로직 구현 |

## 꼬리 질문 및 답변

### Q: 어떤 데이터 프로젝트에 참여하고 싶나요?

**답변**:
```
"우선순위 3가지:

1. 당근알바 구인 성공률 예측
   - 제공된 자료에서 5,000만 지원이 있었다고 했는데
   - 어떤 공고가 채용까지 연결되는지 모델링하고 싶습니다

2. 비즈프로필 광고 효과 측정
   - 로컬 광고의 ROAS를 정확히 측정하는 모델
   - 동네 주민과 가게의 매칭 최적화

3. 매너온도 개선
   - 가짜 리뷰 탐지 모델
   - 시간 가중치가 반영된 신뢰도 지표

단기적으로는 데이터 품질 개선에도 기여하고 싶습니다."
```

### Q: 다른 회사도 많은데 당근이 특별한 이유는?

**답변**:
```
"3가지 차별점:

1. 하이퍼로컬 데이터의 독특함
   - 대부분의 플랫폼은 글로벌/국가 단위
   - 당근은 동네 단위 데이터 = 위치 기반 ML의 흥미로운 문제

2. 비즈니스 모델의 명확성
   - 광고 중심의 흑자 구조 = 데이터가 직접 수익으로 연결
   - 데이터 분석의 임팩트가 명확함

3. 성장 단계
   - MAU 정체 속 신규 서비스 확장 중
   - 데이터 인프라 확충이 필요한 시기 = 기여할 기회"
```

### Q: 당근의 단점은 뭐라고 생각하나요?

**답변** (주의: 긍정적으로 포장):
```
"성장 중인 과제들:

1. MAU 정체
   - 신규 사용자 유입이 어려운 환경
   - → 생활밀착형 서비스로 전환율 높이는 데이터 과제

2. 광고 의존도 99.7%
   - 수익 다각화가 필요
   - → 당근알바 수수료 모델 등 검증할 데이터 분석 기회

3. 지역별 편차
   - 수도권 중심 활성화
   - → 지방 동네 활성화를 위한 데이터 인사이트 필요

이런 과제들이 오히려 데이터 분석가에게는 기회라고 봅니다."
```
