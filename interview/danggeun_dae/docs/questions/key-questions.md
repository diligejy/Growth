# 핵심 질문 10선 (면접 준비 우선순위)

> 시간이 없을 때 우선 준비해야 할 질문들

---

## 질문 선택 기준

- **빈도**: 당근 DAE 면접에서 자주 나오는 질문
- **난이도**: 중간 난이도 (너무 쉽거나 어렵지 않음)
- **커버리지**: 기술 + 비즈니스 + 컬처핏 균형

---

## 핵심 질문 리스트

### [기술] Q1. 중고거래 스타 스키마 설계
**예상 시간**: 5분 답변 + 5분 꼬리질문

**핵심 답변 포인트**:
- Fact Table: transaction_id, 날짜, 구매자/판매자/상품/위치 FK, 가격, 상태
- Dimension: 사용자, 상품, 카테고리, 위치, 시간
- 파티션: transaction_date, 클러스터링: location_id, category_id

**꼬리질문 대비**:
- "왜 Snowflake가 아닌 Star Schema인가?" → 쿼리 성능과 분석가 이해도

---

### [기술] Q2. 재방문율 SQL 쿼리
**예상 시간**: 5분 답변 + 5분 꼬리질문

**핵심 답변 포인트**:
- CTE로 첫 방문 코호트 생성
- 윈도우 함수로 재방문 여부 체크
- 7일, 30일 리텐션 계산

**꼬리질문 대비**:
- "당근알바 채용 전환율은 어떻게 측정하나요?" → view → apply → interview → hire 퍼널

---

### [기술] Q3. BigQuery 비용 최적화
**예상 시간**: 5분 답변 + 5분 꼬리질문

**핵심 답변 포인트**:
- 파티셔닝/클러스터링
- SELECT * 지양
- Materialized View 활용
- dbt incremental model

**꼬리질문 대비**:
- "dbt incremental 전략은?" → last_run_timestamp, MERGE 문 활용

---

### [기술] Q4. Airflow Idempotency
**예상 시간**: 5분 답변 + 3분 꼬리질문

**핵심 답변 포인트**:
- INSERT OVERWRITE 방식
- UPSERT (MERGE) 패턴
- 실행 ID 기반 중복 실행 방지

**꼬리질문 대비**:
- "동시 실행되면?" → concurrency 설정, INSERT OVERWRITE로 결과 일관성

---

### [비즈니스] Q5. 당근 데이터 조직의 핵심 문제
**예상 시간**: 3분 답변 + 3분 꼬리질문

**핵심 답변 포인트**:
- MAU 정체 속 DAU/사용시간 성장
- "매일 쓰는 앱" 전환과 신규 수익 모델 발굴
- 생활밀착형 서비스 퍼널 최적화

**꼬리질문 대비**:
- "구체적으로 어떤 데이터 분석이 필요하나요?" → 알바 매칭 효율, 광고 효율-UX 균형

---

### [비즈니스] Q6. "동네 연결" 측정 지표
**예상 시간**: 3분 답변 + 3분 꼬리질문

**핵심 답변 포인트**:
- 동네별 거래 밀도 (거래 건수/사용자 수)
- 동네별 응답률 (채팅 응답률)
- 동네 커뮤니티 참여도
- 재거래율

**꼬리질문 대비**:
- "동네별로 차이가 큰데 어떻게 비교하나요?" → 인구 밀도, 상권 정규화

---

### [비즈니스] Q7. 매너온도 개선 데이터
**예상 시간**: 3분 답변 + 3분 꼬리질문

**핵심 답변 포인트**:
- 거래 완료 데이터 (무산 vs 실제 거래)
- 양방향 평가 + 평가자 신뢰도 가중치
- 행동 패턴 (노쇼, 분쟁)
- 시간 가중치 (최근 평가에 높은 가중치)

**꼬리질문 대비**:
- "가짜 리뷰 어떻게 탐지하나요?" → IP/디바이스 집중도, 텍스트 유사도

---

### [컬처핏] Q8. 기술적으로 불가능한 요청을 받았을 때
**예상 시간**: 3분 답변 + 2분 꼬리질문

**핵심 답변 포인트**:
- 요청 의도 파악 (어떤 비즈니스 문제?)
- 대안 제시 (근사치, 샘플링, 쿼리 최적화)
- 장기적 해결책 (데이터 마트, 셀프서비스)

**꼬리질문 대비**:
- "PO가 지금 당장이라고 하면?" → 긴급도 확인, 샘플링으로 1시간 내 제공

---

### [컬처핏] Q9. 비즈니스 의미 없는 프로젝트를 받았을 때
**예상 시간**: 3분 답변 + 2분 꼬리질문

**핵심 답변 포인트**:
- 비즈니스 가치 재검토 (누가, 어떤 결정에 사용?)
- MVP로 가치 검증 제안
- DAE 역할 확대 (인사이트 도출 참여)

**꼬리질문 대비**:
- "이미 진행 중일 때 중단 요청이 오면?" → 산출물 자산화, 프로세스 개선 제안

---

### [컬처핏] Q10. 왜 당근인가?
**예상 시간**: 2분 답변 + 2분 꼬리질문

**핵심 답변 포인트**:
- 동네 생활 플랫폼에 대한 애정 (구체적 경험 언급)
- DAE로 기여하고 싶은 부분 (알바 매칭, 광고 최적화)
- 기술적 강점 (dbt, BigQuery 경험)

**꼬리질문 대비**:
- "어떤 데이터 프로젝트에 참여하고 싶나요?" → 알바 구인 성공률 예측 모델

---

## 학습 우선순위

### Phase 1: 필수 (면접 전날 밤)
1. Q10 (왜 당근인가) - 답변 외우기
2. Q1, Q2 (기술 기본) - 핵심 포인트 암기
3. Q5 (비즈니스 문제) - 프레임워크 숙지

### Phase 2: 권장 (면접 당일 아침)
4. Q3, Q4 (BigQuery, Airflow) - 최적화 포인트 복습
5. Q6, Q7 (동네 연결, 매너온도) - 지표 정리

### Phase 3: 심화 (시간 여유 시)
6. Q8, Q9 (컬처핏) - 협업 스토리 준비

---

## 답변 시간 관리

| 질문 유형 | 권장 시간 | 비고 |
|----------|----------|------|
| 기술 질문 | 5-10분 | 코드 설명 포함 시 길어짐 |
| 비즈니스 질문 | 3-5분 | 간결하게 핵심만 |
| 컬처핏 질문 | 2-3분 | 스토리텔링 중심 |

**총 예상 시간**: 45-60분 (꼬리질문 포함)
