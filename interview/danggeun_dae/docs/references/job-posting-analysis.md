## 면접 답변에 반영할 포인트

### "왜 당근인가?" 업그레이드

```
"3가지 이유에서 지원했습니다.

첫째, '매일 데이터를 통해 사용자를 위한 의사결정을 한다'는 
비전에 공감합니다. 사용자에게 더 좋은 경험을 주기 위한 
데이터 기반 의사결정 문화를 만들고 싶습니다.

둘째, dbt와 Airflow를 활용한 데이터 엔지니어링 환경이 
매력적입니다. 'dbt 도입하며 마주한 7가지 문제들' 글을 읽고
당근 데이터 팀의 문제 해결 방식에 깊은 인상을 받았습니다.

셋째, 전사 주요 지표를 정의하고 데이터 거버넌스를 구축하는 
경험을 통해 데이터 분석가들이 '뛰어놀 수 있는 환경'을 
만들고 싶습니다."
```

### "어떤 기여를 할 수 있나?" 업그레이드

```
"전사 주요 데이터 마트 설계와 지표 체계화에 기여하고 싶습니다.

특히:
1. Fact/Dimension 테이블을 dbt로 모델링하여 
   분석가들이 쓰기 좋은 데이터 환경 구축

2. 데이터 품질 자동화 (dbt tests)와 
   관측성(Observability) 체계 구축

3. 데이터 거버넌스 및 데이터 카탈로그를 통한 
   조직 전체 데이터 신뢰성 향상

이를 통해 데이터가 단순히 쌓이는 것이 아니라
빠르고 정확한 인사이트로 연결되도록 하겠습니다."
```
